DAY BY DAY — IPHONE FITNESS TRACKER

FILES: index.html, manifest.webmanifest, icon.svg

QUICK START (on a computer):
1. Extract the ZIP. Open index.html in a browser to try it.
2. For iPhone Home Screen installation, publish all three files together on a static HTTPS host (for example, GitHub Pages or Netlify).
3. Open the HTTPS address in Safari on your iPhone. Tap Share > Add to Home Screen > Add.
4. Log meals as you eat, and add weight, sleep, steps, screen time, workout, and private Yes/No whenever convenient.
5. At day's end tap "Save image card" to download a PNG. On iPhone, use Share > Save Image / Save to Photos if it first appears in Downloads or Files.
6. Go to Settings > Export JSON backup regularly. Save the JSON to Files/iCloud Drive; use Restore backup to recover.

FREE HOSTING WITH GITHUB PAGES (OPTIONAL):
- Create a new GitHub repository.
- Upload index.html, manifest.webmanifest and icon.svg to the repository root.
- Open Settings > Pages, select Deploy from a branch, branch main and /(root), and save.
- Open the HTTPS Pages URL in iPhone Safari and Add to Home Screen.
- Hosting the files does not send logged data to GitHub; entries stay in browser storage.

IMPORTANT:
- This version does not send its own push notifications. Keep your existing ChatGPT 9 PM reminder.
- The app does not automatically calculate food nutrition. Enter estimated calories/protein from labels or from your ChatGPT meal reviews; blank nutrition is explicitly uncounted.
- Data stays on this device/browser and does not automatically sync across devices. Clearing browser data or changing domains can erase or separate records.
- Private Yes/No is opaque but NOT encrypted or password-protected. Exported backups and image cards include it.
- The app has no server, sign-in, paid service, or coding requirement for daily use.
